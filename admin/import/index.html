Import

Bring posts and media in from a WordPress export file (WXR).

1. Choose a WordPress export

From the old site: WP Admin → Tools → Export → All content. Posts and their media are imported; pages and comments are not. Categories and tags both become tags here. Nothing is written until you confirm the preview below.

Result

Media fetch blocked?

Some hosts block automated requests for images entirely, no matter how "Confirm import" asks — SiteGround's AI Anti-Bot Protection is a known case, with no self-service allowlist. If "Media that failed to fetch" above shows every file failing, download the wp-content/uploads folder from the old host (SiteGround: Site Tools → File Manager, or SFTP) and select it here instead. Files are matched to the export by filename; anything that doesn't match is reported, not silently skipped. Run "Confirm import" again afterward to finish creating posts against the media you've uploaded.
